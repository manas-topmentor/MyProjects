A JSON-based Library Management System is a good way to demonstrate File I/O, JSON, functions, dictionaries, lists, validation, date handling, and exception handling.

One clarification: JSON does not have a true SQL-style PRIMARY KEY. We can enforce the same rule in Python by making book_id unique and refusing to add a book if that ID already exists.

Features included
Add books
Prevent duplicate Book IDs
Register members
Issue books
Set due date
Return books
Automatically calculate late fines
View available books
View issued books
View members
Persistent storage using JSON files
Input validation
Error handling
Automatic creation of JSON files
Fine rule used

₹5 per day for every day a book is returned after its due date.
