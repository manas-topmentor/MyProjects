A. BANKING SYSTEM: Banking Management System using Python + MySQL. It includes all the features uses MySQL constraints plus Python validation to prevent duplicate accounts.
Features included
1.	Create account 
2.	Duplicate account prevention 
3.	Deposit money 
4.	Withdraw money 
5.	Balance enquiry 
6.	Transfer money 
7.	View account details 
8.	Transaction history 
9.	Create loan 
10.	Record loan/EMI payments 
11.	Automatic late-payment penalty 
12.	Close account 
13.	MySQL database/table creation automatically 
14.	Transaction rollback for failed transfers/deposits/withdrawals 
15.	Loan EMI calculation using the standard reducing-balance formula 
Database design
The program creates these tables automatically:
•	accounts 
•	transactions 
•	loans 
•	loan_payments
